## 维护约定

- 功能变更时同步更新需求状态、方案设计及验收记录。
- 区分当前实现、目标行为和待验证项；不把规划写成完成成果。
- 文档中的源码链接使用仓库相对路径，便于本地及 GitHub 阅读。
- 数据库、模型密钥等本机配置放在被 Git 忽略的 `application-local.yml` 中，不写入文档或提交。
